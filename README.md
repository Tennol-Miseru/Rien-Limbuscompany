# Rien-LimbusCompany

A Minecraft combat mod featuring nine transforming weapons, cinematic combat arts, and a formidable boss inspired by Limbus Company.

Rien-LimbusCompany introduces the Oracle Arsenal — Twin Serpent Staff, a mysterious weapon capable of transforming into nine distinct forms, each with its own combat style, animations, and special effects.

Blink across the battlefield, switch weapons in an instant, and unleash devastating combinations through the power of Furioso.

## Features

- **Nine Unique Weapons** — Nine weapon forms with custom 3D models, animations, and combat effects.
- **Teleportation Combat** — Instantly reposition around enemies, leaving blue petals and dark afterimages behind.
- **Three Furioso Arts** — Unleash Furioso-Replica, Furioso [Crescendo], or the devastating Furioso [Lacrimosa-Crescendo] when your health falls below 50%.
- **Hermes System** — Accumulate charges through combat to unlock powerful abilities and defensive effects.
- **The Heart Effect** — Gain increased attack speed, movement speed, and melee damage, accompanied by golden particles and afterimages.
- **Rien Boss Battle** — Face Rien in a two-phase encounter featuring weapon switching, aggressive combat patterns, teleportation, and cinematic attacks.
- **Prescript Pager** — Receive mysterious instructions, discover hidden references, and follow the path toward challenging Rien.
- **Cinematic Combat** — Custom character animations, dynamic camera movements, unique sound effects, and dramatic finishing attacks.

## Required Dependencies

The following mods are required for Rien-LimbusCompany to function properly:

- **Fabric API** — A version compatible with Minecraft 1.21.1.
- **Player Animator (KosmX)** — Version 2.0.4 or later, compatible with Minecraft 1.21.1.

Additional Requirements:

- Minecraft Java Edition 1.21.1
- Fabric Loader 0.16.0 or later
- Java 21 or later

Please install both required mods before launching the game. Missing dependencies may prevent Rien-LimbusCompany from loading.

# Rien-LimbusCompany — 里恩模组

一个以《Limbus Company》相关角色为主题，拥有随机变形武器、华丽战斗演出与专属 Boss 战的 Minecraft 模组。

Rien-LimbusCompany 以「神谕终端·双蛇杖」为核心，加入了一套能够变幻为九种不同兵装的战斗系统。

从刺剑的迅捷突刺、战锤的沉重打击，到巨镰撕裂空间般的斩击，每一种武器都拥有独立的模型、攻击动作与特殊效果。

玩家可以通过瞬移不断变换武器，在敌人之间穿梭，并以九种兵装的连续攻击释放名为 Furioso 的战斗技艺。

## 模组特色

- **九种独立兵装** —— 手斧、锥、手半剑、刺剑、锤子、大剑、长枪、鞭子与镰刀，各具独特的攻击动作与战斗效果。
- **高速瞬移战斗** —— 在敌人周围瞬间移动、随机切换武器，留下蓝色花瓣与漆黑的身形残影。
- **三种 Furioso** —— 释放 Furioso-Replica、Furioso [Crescendo]，或在生命值低于半数时发动更强大的 Furioso [Lacrimosa-Crescendo]。
- **代行·赫尔墨斯** —— 通过战斗积累力量，获得释放特殊技能所需的能量，并提升瞬移后的防护能力。
- **特殊状态「心」** —— 提升攻击速度、移动速度与近战伤害，身体周围浮现金色光芒，并在移动时留下短暂的黄金残影。
- **里恩 Boss 战** —— 与拥有两阶段战斗机制的里恩交锋，面对他的瞬移、九式连击、攻防节奏变化，以及半血后的摘面具演出。
- **神秘的指令机** —— 接收意味深长的指令，发现其中的隐藏彩蛋，并循着指令开启与里恩的试炼。
- **专属战斗演出** —— 包含全身攻击动画、电影式镜头、特殊音效与极具表现力的终结技。

## 必需前置模组

运行 Rien-LimbusCompany 前，请确保已安装以下模组：

- **Fabric API** —— 适用于 Minecraft 1.21.1 的兼容版本。
- **Player Animator（KosmX）** —— 适用于 Minecraft 1.21.1 的 2.0.4 或更高版本。

其他运行要求：

- Minecraft Java Edition 1.21.1
- Fabric Loader 0.16.0 或更高版本
- Java 21 或更高版本

请在启动游戏前安装上述两个前置模组。缺少必要依赖可能导致 Rien-LimbusCompany 无法正常加载。
